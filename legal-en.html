3. Hosting & Server Log Files (GitHub Pages)

This website is hosted by GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). GitHub is the technical recipient of your data to enable the delivery of the website.

When you access our website, the web server (GitHub) automatically collects technical information in so-called server log files. This is technically necessary to display the website and to ensure stability and security. This data includes:

  • IP address of the requesting device
  • Date and time of access
  • Name and URL of the retrieved file
  • Website from which access is made (referrer URL)
  • Browser and operating system used

Purpose: Processing is carried out to ensure network security and error analysis.

Legal basis: Legitimate interest in the secure and stable operation of the website (Art. 6(1)(f) GDPR; Art. 31(1) FADP).

Data transfer to the USA: Since GitHub is based in the USA, data may be transferred to the USA. The transfer is based on the provider's applicable safeguards (including Standard Contractual Clauses and/or certification under the EU-US Data Privacy Framework).

Storage duration: Log files are temporarily stored according to GitHub's guidelines and are generally deleted automatically after a few days.

Right to object: Since the collection of this data is technically mandatory for the provision and security of the website, users have no possibility to object.

Our website contains links to external platforms, in particular Steam (Valve Corporation) and embedded videos from YouTube.

  • Steam: When you click on a link that leads to Steam (e.g., to view or buy the game), you leave our website. From this point on, the privacy policies of Valve Corporation apply. Data may be transferred to the USA.

6. Local Data Processing in the Game

The game "Tactilite" is an offline application. All savegames, tactics, and progress are stored exclusively locally on your device. No personal game data is transmitted to our servers.

7. Steam Friends List & Statistics (In-Game)

The game "Tactilite" offers an optional feature that lets you see a list of your Steam friends who also own the game, along with selected game statistics (e.g., number of cups and leagues won, seasons played, in-game money spent, best finish, and preferred playstyle).

Important: This data is retrieved exclusively via the official Steamworks interface of Valve Corporation and displayed directly in your game. No such data is transmitted to Eloori Interactive, and no dedicated servers are operated for storage.

For this purpose, the feature processes the following data provided by Steam:

  • Steam IDs and public display names (persona names) of your Steam friends
  • The game statistics stored for Tactilite of these friends (provided their Steam privacy settings allow this)

Purpose: Displaying the friends list and comparing game progress within the game.

Legal basis / consent: The feature is optional. When you open it for the first time, you are informed in-game about this data processing and can decide for yourself whether the friends' data should be loaded. Processing is carried out exclusively on the basis of your consent (Art. 6(1)(a) GDPR; Art. 6(6) FADP), which you can withdraw at any time with effect for the future by no longer using the feature.

Recipients & data transfer: The data is provided by Valve Corporation via Steam. Data may be transferred to the USA. The privacy policy of Valve applies.

Storage duration: The data is processed only at runtime in memory and is not permanently stored by the game.
